SEC 02

核心人才戰略：Forward Deployed Engineering（FDE）與實務產出標竿

不再訓練只會做投影片、寫報告或上網找資料的學生！在「程式碼交給 AI、流程與人交給領域專家」的時代，商學院與非電資科系反而是最能落實 FDE 前線部署的主場；從系辦日常流程啟動小量 POC / MVP，直接對標以下全國奪冠與已上線之實務作品集。

NUTC FDE CORE EQUATION // 前線部署工程核心分工
程式碼交給 AI ＋ 業務流程、數字與人交給商學院 ＝ FDE 前線部署工程師
1. 為什麼商學院是 FDE 最佳主場？ PROCESS & DOMAIN FIRST

企業與學校現場真正的卡關點不在寫程式語法，而在拆解 ERP 毛利歸因、財稅法規、國貿單據、排班與簽核流程。AI 接手寫碼後，最懂商業邏輯與組織中「人」的商學院師生，最能前線部署成可用系統。

2. 怎麼起步？從「系辦日常流程」做小量 POC / MVP 1–2W POC → 6W MVP

不強求一次翻修校務大系統：先走進全校最近的場域——系辦，挑一件每週重複耗時的日常雜務（如法規問答、招生戰情、合約檢核），1–2 週快速做小量 POC（概念驗證），驗證有效再收斂成 MVP（最小可行產品）。

3. 極致實作課程帶動（終結簡報、報告與找資料） HANDS-ON DELIVERY

直接以高度實作的課程取代「找資料做 PPT 交報告」：要求學生與教師親手產出 即時數字儀表板、3D 地震空間視覺、不出本機的地端 LLM，用作品與全國競賽實績證明實力。
