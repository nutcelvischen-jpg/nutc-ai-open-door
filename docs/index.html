SEC 02

核心人才戰略：Forward Deployed Engineering（FDE）與四大實務產出方向

不再訓練只會做投影片、寫報告或上網找資料的學生！在「程式碼交給 AI、流程與人交給領域專家」的時代，商學院與非電資科系反而是最能落實 FDE 前線部署的主場；從系辦日常流程啟動小量 POC / MVP，全面聚焦可實際運作的系統產出。

NUTC FDE CORE EQUATION // 前線部署工程核心分工
程式碼交給 AI ＋ 思考、流程與人交給學生與現場 ＝ FDE 前線部署工程師
1. 為什麼「思考與流程」才是核心主場？（全校共通） THINKING & PROCESS FIRST

企業與學校現場真正的卡關點不在寫程式語法，而在思考並拆解 ERP 毛利歸因、進銷存與國貿單據、排班與簽核流程。AI 接手寫碼後，全校六大學院師生不必再被學院界線框住，都能用思考主導流程並前線部署實用系統。

2. 怎麼起步？從「系辦日常流程」做小量 POC / MVP 1–2W POC → 6W MVP

不強求一次翻修校務大系統：先走進全校最近的場域——系辦，挑一件每週重複耗時的日常雜務（如法規問答、合約格式檢核），1–2 週快速做小量 POC（概念驗證），驗證有效再收斂成 MVP（最小可行產品）。

3. 以思考解決問題為主 × 商學院參與各項比賽（順帶 iPAS 交代） PROBLEM-SOLVING & COMPETE

不分任何學院界線，課程核心一律教導學生獨立思考、解決問題與實用落地（iPAS 認證全校共通、順帶交代）；商學院學生更能突破寫碼門檻主動參與各項比賽、跨域挑戰實作賽事，以運作成品取代報告 PPT。
